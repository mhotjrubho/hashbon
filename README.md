# חשבון

מערכת קוד פתוח לניהול כספים אישי, הפועלת מקומית במחשב Windows באמצעות Electron ו-React.

## עקרונות
- ממשק בעברית ובכיווניות RTL.
- הנתונים נשמרים במחשב המשתמש, במסד נתונים SQLite.
- ללא חשבון משתמש, שרת מרכזי או שירות OCR בתשלום.
- החזרי הוצאות נשמרים בנפרד מהכנסות.
- סריקת תלושי שכר מקומית מתוכננת לשלב הבא.

## דרישות
- Windows 10/11
- Node.js בגרסת LTS עדכנית (מומלץ Node 22)

## התקנה למפתחים
```bash
npm install
npm run dev
```

## בניית מתקין Windows
```bash
npm run dist:win
```
קובץ ההתקנה יופיע בתיקיית `release`.

## מבנה
- `electron/` – תהליך Electron הראשי ו-Preload מאובטח.
- `src/` – ממשק React והעיצוב.
- `package.json` – תלויות ופקודות בנייה.

## פרטיות ואבטחה
המידע הכספי והתלושים הם מידע רגיש. אין להעלות למסד הנתונים או ל-Git קובצי נתונים אישיים, תלושי שכר, גיבויים או סיסמאות. בשלב הנוכחי יש לבדוק היטב את התוכנה לפני שימוש בנתונים אמיתיים.

## מצב הפיתוח
גרסה ראשונית: סקירה כללית, רישום הכנסה/הוצאה/החזר, SQLite מקומי ומסכי בסיס. סריקת תלושים, גיבוי/שחזור, דוחות מתקדמים וחישובי מס/מעשרות עדיין בפיתוח.
