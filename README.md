# חשבון

מערכת שולחנית מקומית בעברית לניהול כספים אישיים, שעות עבודה ותלושי שכר. הנתונים נשמרים במחשב המשתמש.

## מה כלול
- לוח בקרה חודשי להכנסות, הוצאות, החזרים, יתרה ושעות עבודה.
- תנועות כספיות עם חיפוש, סינון, עריכה ומחיקה.
- סוג נפרד להחזר הוצאות. החזרים אינם מתווספים לסך ההכנסות.
- רישום שעות עבודה לפי תאריך, מעסיק, שעות ותעריף לשעה.
- ארכיון תלושי שכר: שמירת PDF/תמונה מקומית והזנה ידנית של ברוטו, נטו וניכויים.
- OCR מקומי לתמונות באמצעות Tesseract המותקן במחשב. אין שירות OCR בענן. קובצי PDF סרוקים אינם נתמכים ב-OCR בשלב זה.
- דוחות חודשיים.
- הגדרות, גיבוי ושחזור של מסד הנתונים.
- ממשק RTL, ללא Google Fonts או תלות ברשת בזמן שימוש.

## התקנה ופיתוח
נדרש Node.js 22 ומעלה ו-Windows 10/11.
```bash
npm install
npm run dev
```

## יצירת מתקין EXE
```bash
npm run dist:win
```
המתקין יופיע בתיקיית `release`.

## OCR מקומי
כדי להפעיל OCR לתמונות תלושים:
1. התקן Tesseract OCR ב-Windows.
2. ודא שהפקודה `tesseract` זמינה ב-PATH.
3. התקן את נתוני השפה עברית (`heb`) ואנגלית (`eng`).
4. פתח תלוש תמונה במערכת ולחץ על זיהוי טקסט.
הטקסט מזוהה ונשמר מקומית. יש לבדוק ידנית כל סכום לפני הזנה לשדות השכר.

## מיקום הנתונים
מסד הנתונים והקבצים נשמרים בתיקיית `userData` של Electron עבור המשתמש הנוכחי. ב-Windows זו בדרך כלל תיקייה תחת `%APPDATA%\hashbon`. אין להעלות נתונים אישיים או תלושי שכר ל-Git.

## פרטיות וגיבויים
הנתונים נשמרים מקומית. קובץ גיבוי מסד הנתונים אינו כולל את קובצי התלושים עצמם; כדי להעביר התקנה למחשב אחר יש להעתיק גם את תיקיית `payslips` שבתיקיית הנתונים. יש לשמור גיבויים במקום מוגן.

## מגבלות ידועות
- OCR זמין כרגע לתמונות בלבד, ודורש התקנה מקומית של Tesseract ושפות.
- אין עדיין סנכרון בין מחשבים, שירות ענן או משתמשים מרובים.
- אין חישוב אוטומטי של מס הכנסה, ביטוח לאומי או זכויות שכר. הנתונים מוזנים מהתלוש בפועל.
- יש לבדוק את הנתונים שחולצו או הוזנו מול תלוש המקור.
